## 4. 关键问题清单（来自 9/17、10/10 的质询）

1. **角色混淆**：爱干净的人 / 制造垃圾的人 / 付费用户 / 受益者，到底服务谁？
2. **证据缺口**：访谈了几个人？原话是什么？有没有具体冲突事件？没有证据就只是假设。
3. **需求真实性 vs 付费意愿**：痛点真实不等于愿意下载、填写、打卡、付费。
4. **机制问题**：标准、检查记录、公示奖惩、舍长授权，本质是"权力与规则"问题，不是"缺工具"。
5. **反直觉检验**：如果明天出现一个能自动记录、公示、奖惩的完美 App，爱干净的人敢用吗？会不会更破坏关系？
6. **新方向风险（10/18）**：可复制性强、作用模糊，如何做出差异化与真实需求？
